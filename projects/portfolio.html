Project Overview

About the Project

A personal portfolio website designed to showcase my skills, projects, certificates, and professional experiences. The site serves as a comprehensive overview of my capabilities in cloud computing, web development, and IT infrastructure, giving visitors a clear picture of what I can do.

Project Goal

To create an evolving digital portfolio that grows alongside my career, continuously updated with new projects, skills, and achievements throughout my BTS studies and beyond.

Technology Stack

HTML5

Semantic HTML structure providing the foundation for all pages, ensuring accessibility and proper document organization.

CSS3

Custom styling with modern CSS features including glass morphism effects, responsive design, flexbox layouts, and smooth animations.

JavaScript

Client-side functionality including the internationalization (i18n) system for multi-language support, interactive elements, and dynamic content loading.

GitHub Pages

Free static site hosting through GitHub Pages, enabling easy deployment and version control for continuous updates.

Features

Multi-Language Support

Full internationalization with English and French translations, allowing visitors to view the portfolio in their preferred language.

Glass Morphism Design

Modern UI aesthetic with frosted glass effects, subtle animations, and a cohesive dark theme throughout.

Project Showcases

Dedicated pages for each project with detailed descriptions, technology stacks, and downloadable documentation.

Certificate Gallery

Display of professional certifications with links to official verification on Credly.

Future Plans

This portfolio is a living project that will continue to evolve:

• Add new projects as they are completed during BTS and beyond

• Include additional certifications and achievements

• Enhance features and improve the user experience

• Keep content updated with latest skills and experiences
