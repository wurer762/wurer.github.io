Server Virtualization Systems In Progress

Proxmox VE & VMware ESXi — High Availability Specialization

VIRCL Course

Project Overview

About the Project

A comprehensive hands-on project comparing two enterprise-grade type-1 hypervisors: Proxmox VE and VMware ESXi. Working on physical HP servers in the school server room, the team deployed both virtualization environments and implemented every major feature from VM creation and management to live migration, backups, snapshots, and templates. The group's specialization topic is High Availability — covering its theoretical foundations and practical implementation on both platforms.

Project Goal

To acquire in-depth expertise in enterprise server virtualization, become proficient in both Proxmox VE and VMware ESXi, and demonstrate the configuration and benefits of High Availability in a virtualized environment.

Team

Würth Eric, Simon Max, Kugener Sven

Technology Stack

Proxmox VE

Open-source type-1 hypervisor based on Debian Linux and KVM. Used to deploy and manage all virtualization features including clustering, live migration, and High Availability configuration.

VMware ESXi

Industry-leading commercial type-1 hypervisor from VMware. Managed via the vSphere Client and vCenter Server, covering VM lifecycle, cloning, snapshots, backups, and HA configuration.

vCenter Server

VMware's centralized management platform, required for advanced features such as vMotion live migration, DRS, and High Availability across ESXi hosts.

TrueNAS (Remote Storage)

The CLOIF2 NAS servers running TrueNAS provide shared remote storage over NFS and iSCSI protocols, used for VM file storage and live migration between hypervisors.

Topics Covered

General Features

• Deployment of both hypervisor environments on physical HP servers

• VM creation and management via GUI and CLI on both platforms

• Installation of Windows client and Linux server operating systems in VMs

• Hardware reconfiguration of running VMs (CPU, RAM, storage, NICs)

• VM cloning, exporting, and template creation

• Snapshots — creation, rollback, and management

• Hypervisor configuration backup and VM backup (built-in and scripted)

• Live migration of VMs between storage targets and between hypervisor nodes

• Remote storage integration via NFS and iSCSI using TrueNAS

• User and permission management on both hypervisors

Specialization — High Availability

High Availability (HA) ensures that virtual machines automatically restart on another node in a cluster when a host failure is detected, minimizing downtime in production environments.

• Theoretical concept of HA: quorum, fencing, and failover mechanisms

• HA implementation and configuration on Proxmox VE using built-in HA Manager

• HA implementation on VMware ESXi using vSphere HA within a vCenter cluster

• Do's and don'ts: shared storage requirements, network redundancy, and avoiding split-brain scenarios
