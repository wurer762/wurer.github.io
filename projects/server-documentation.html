Project Overview

About the Project

A comprehensive documentation project covering the setup and configuration of a NAS server running TrueNAS Community Edition. The document covers everything from the physical hardware of the Intel SR2600URBRPR server, to OS installation, network configuration, storage pool creation, user management, and file sharing.

Team

Würth Eric, Simon Max, Kugener Sven

Topics Covered

NAS Fundamentals

Explains what a NAS is and how it compares to DAS (Direct Attached Storage) and SAN (Storage Area Network), covering the differences between file-level and block-level storage and the benefits of separating compute from storage.

Hardware

Detailed documentation of the Intel SR2600URBRPR 2U rack server used in the project, including full hardware specifications, annotated front and back panel port descriptions, internal component layout, and the RAID controller with backup battery.

• 2× Intel Xeon X5650 CPUs, 64 GB RAM, 2× 160 GB SATA drives, 3× 146 GB SAS drives (RAID)

OS Installation — TrueNAS Community Edition

Covers TrueNAS Community Edition (formerly TrueNAS SCALE), an open-source Linux/Debian-based NAS OS built on ZFS. Includes background on iXsystems, release history, cost (free), key features, and a pros/cons comparison.

Network Configuration

Step-by-step configuration of the TrueNAS console and web panel: setting the admin password, enabling DHCP, accessing the web UI, switching to a static IP, and setting the hostname.

Storage & File Sharing

Creating storage pools for both software RAID (mirror) and hardware RAID (stripe), creating users and datasets, setting ACL permissions, and connecting to shared folders from both Windows (SMB) and Linux (Nautilus). Also covers the difference between iSCSI (block-level) and NFS/SMB (file-level) protocols.

Technical Stack

TrueNAS Community Edition

Open-source NAS OS built on Debian Linux with the ZFS file system. Provides storage management, file sharing protocols, snapshots, RAID, encryption, and a web-based UI out of the box.

File Sharing Protocols

SMB for Windows clients, NFS for Linux/Mac clients, and iSCSI for block-level access. The documentation covers practical setup and testing of SMB shares and explains when to use iSCSI over NFS/SMB.

Intel SR2600URBRPR

A 2U rack-mounted enterprise server with dual Xeon X5650 CPUs, 64 GB RAM, a hardware RAID controller with backup battery, and support for both SATA and SAS drives.

My Part in the Project

Within the three-person team, I was responsible for the setup and live demonstration side of the project.

• Installed the TrueNAS Community Edition operating system on the server.

• Configured the software RAID and handled user management.

• Prepared and delivered the live demonstration of a shared folder between the TrueNAS server and a Windows client.
