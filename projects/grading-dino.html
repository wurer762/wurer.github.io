Grading Dino

School Project - Educational Application

Project Overview

About the Project

GradingDino is a grade management web application developed as a BTS Cloud Computing group project by a four-person team. The system enables teachers to create classrooms, manage student grades, and write observations, while students can track their academic progress and maintain personal notes.

Key Features

• Role-based access control (Admin, Teacher, Student)

• Classroom creation and management

• Grade tracking by semester and subject

• Multiple grading scale support (20-point, 60-point, letter grades)

• Teacher observation records

• Personal notes functionality for students

• Django admin panel for user and scale management

Technologies Used

Backend: Python

Deployment: Docker & Docker Compose

Architecture: Multi-container web application

User Roles: Administrator, Teacher, Student

Features

For Students

• View grades and academic results by semester and subject

• Access personalized dashboard

• Track progress across multiple grading scales

• Maintain personal notes for academic organization

For Teachers

• Create and manage classrooms

• Grade students using multiple scale formats (20-point, 60-point, letter grades)

• Write and track observation records for students

• Update grades with concurrent write support

For Administrators

• Full system access through Django admin panel

• User management and role assignment

• Grading scale configuration and customization

• System-wide settings and security controls

Technical Stack

Framework & Language

Built with Django 5.0 and Python 3.11-slim, leveraging Django's "batteries included" approach for rapid development with built-in authentication, ORM, admin panel, forms, validation, and security features.

Database

PostgreSQL 16 was selected for its Docker-native integration, concurrent write support allowing multiple teachers to grade simultaneously, and full ACID compliance for data integrity.

Security

Implements Argon2 password hashing, developed at the University of Luxembourg and winner of the Password Hashing Competition (2015). Features memory-hard design resistant to GPU/ASIC brute-force attacks.

Frontend

Uses Pico.css minimalist framework (~10KB) with server-side rendering through Django templates. All validation and logic handled server-side for enhanced security and simplicity.

Deployment

Containerized with Docker and Docker Compose for environment consistency and production-ready architecture. System starts with a single docker compose up command.
