Grading Dino

School Project - Educational Game Application

Project Overview

About the Project

GradingDino is a Python + Docker web application for managing grades. The system allows students to view their results and professors to create or update grades efficiently.

Key Features

• Role-based access control (Admin, Teacher, Student)

• Grade management and tracking system

• Student and teacher dashboards

• Secure authentication and login system

Technologies Used

Backend: Python

Deployment: Docker & Docker Compose

Architecture: Multi-container web application

User Roles: Administrator, Teacher, Student

Features

For Students

• View grades and academic results

• Access personalized dashboard

• Track progress over time

For Teachers

• Create and update student grades

• Manage class rosters

• View student performance analytics

For Administrators

• Full system access and control

• User management capabilities

• System configuration

Technical Stack

Framework & Language

Built with Django 5.0 and Python 3.11, leveraging Django's "batteries included" approach for rapid development with built-in authentication, forms, validation, and security features.

Database

PostgreSQL 16 was selected for its Docker-native integration, concurrent write support allowing multiple teachers to grade simultaneously, and full ACID compliance for data integrity.

Security

Implements Argon2 password hashing, developed at the University of Luxembourg and winner of the Password Hashing Competition (2015). Features memory-hard design resistant to GPU/ASIC brute-force attacks.

Frontend

Uses Pico.css minimalist framework (~10KB) with server-side rendering through Django templates. All validation and logic handled server-side for enhanced security and simplicity.

Deployment

Containerized with Docker and Docker Compose for environment consistency and production-ready architecture. System starts with a single docker compose up command.
